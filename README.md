# Wesley's Brawler

A belt-scrolling brawler for iPhone and iPad, played in the browser.

Play: https://chris-chamberlain.github.io/wesleys-brawler/

In Safari, use Share → Add to Home Screen to play fullscreen.

Two players: both phones on the same Wi-Fi. One taps 2 PLAYERS → HOST and shares the 4-letter code; the other taps JOIN.
